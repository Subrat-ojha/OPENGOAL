# Subratgoal

OpenGoals — product concept and UI direction

We’re building OpenGoals, an AI-assisted goal execution app inspired by OpenCode’s terminal UI and interaction style. The idea is to make working toward personal goals feel like working with an intelligent coding agent: you open a workspace, see what needs to happen next, report what you’ve done, and let the AI help adjust the plan.

The idea we’re working on

- Choose a goal: Enter something you want to achieve and a target date—or ask AI to suggest a realistic goal and timeframe.

- Generate a plan: AI breaks the goal into milestones and manageable daily tasks.

- Check in every day: Mark tasks complete, or tell the AI in natural language what you accomplished, what went wrong, and what you’ll do next.

- Adapt as you go: The app updates progress and proposes changes when you fall behind or your priorities change.

- Keep AI costs low: Use regular application code for task tracking, progress, deadlines, and streaks. Call AI only when it adds value, such as understanding check-ins, creating plans, or adapting milestones.

The design inspiration is OpenCode—not a generic productivity dashboard. We want its compact terminal-like layout, subdued colors, clear text hierarchy, keyboard-first feel, and focused working area. OpenGoals should feel like a dedicated workspace for making progress, rather than a collection of colorful cards. i wnat this to be covering whole screen
